# Тесты на проверку cоздания заказа и проверку получения данных о заказе по треку с помощью API Яндекс.Самокат
Данный проект содержит автотест для проверки функциональности API, отвечающей за создание заказа, и получение информации о нем по полученному треку.
Содержание автотеста:
- Выполняется запрос на создание заказа.
- Сохраняется номер трека заказа.
- Выполняется запрос на получения заказа по треку заказа.
- Проверяется, что код ответа равен 200.


# Структура проекта.
- `sender_stand_request.py`: модуль для отправки HTTP-запросов к API.
- `data.py`: модуль с данными, которые используются в HTTP-запросах.
- ` create_order_test`: содержит тест для проверки корректности работы API.
- `configuration.py`: конфигурационные данные и функции для работы с API.
- README.md # Документация проекта
- .gitignore # Исключения
    
# Запуск тестов.
- Запуск всех тестов выполняется командой pytest
- Для запуска тестов должны быть установлены пакеты pytest, requests, copy
